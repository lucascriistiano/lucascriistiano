# Hey, I'm Lucas Cristiano! 👋

### Senior AI Software Engineer

I build AI systems and the backends that keep them running. Currently a Senior AI Software Engineer at [HubSpot](https://www.hubspot.com), where I landed through the acquisition of [Warmly](https://www.warmly.ai/) — I spent a year and a half there building AI agents and real-time chat, work that ended up being a core part of what HubSpot bought.

Before that: Staff Software Engineer at [iFood](https://www.ifood.com.br), building support platforms for all three sides of a marketplace serving 55M monthly users, 300K+ merchants, and 400K delivery partners. Before that, Senior Consultant Developer at [Thoughtworks](https://www.thoughtworks.com), delivering systems for multinational clients.

**What I work with:** Go, Kotlin, Java, Spring Boot, Python, LangGraph, JavaScript, React, Node.js, Kafka, Docker, Kubernetes, AWS. Distributed systems by background, applied AI by current obsession — LLMs, RAG, agent orchestration, and the evaluation infrastructure that keeps any of it honest.

**Education:** Master's in Systems and Computing (UFRN), plus postgraduate specializations in Data Engineering & Analysis and Tech Leadership at CESAR School.

Open source enthusiast, permanent beginner at something. Always happy to talk shop.
